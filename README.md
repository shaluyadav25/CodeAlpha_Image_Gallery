CodeAlpha Image Gallery

A responsive Image Gallery project created using HTML, CSS, and JavaScript.

Features

- Responsive image gallery
- Next and Previous image navigation
- Smooth design and layout
- Interactive buttons
- Beginner-friendly JavaScript functionality

Technologies Used

- HTML
- CSS
- JavaScript

Project Description

This project is developed as part of the Frontend Development Internship at CodeAlpha. The gallery allows users to navigate through images using next and previous buttons.
